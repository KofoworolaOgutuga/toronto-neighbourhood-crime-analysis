# Toronto Neighbourhood Crime Analysis

## Overview

This project analyzes crime patterns across selected Toronto neighbourhoods using publicly available Toronto Open Data.

The goal was to examine differences in crime levels and crime rates across neighbourhoods, identify patterns, and consider possible factors that may contribute to higher crime levels.

## Business Questions

- Which Toronto neighbourhoods have higher levels of reported crime?
- How do crime rates compare when population differences are considered?
- What crime patterns can be observed across the selected neighbourhoods?
- What actions or factors may help explain differences in crime?
- What recommendations could help address the issue?

## Neighbourhoods Analyzed

The analysis focused on:

- Waterfront Communities-The Island
- Church-Yonge Corridor
- West Humber-Clairville
- Bay Street Corridor
- Moss Park

## Analysis

The project involved organizing and analyzing crime data, comparing neighbourhood crime levels and rates, and using population information to provide additional context.

Excel and Microsoft Access were used to organize and analyze the data, while PowerPoint was used to communicate the findings and recommendations.

## Key Takeaways

The analysis showed that crime levels varied substantially between the selected Toronto neighbourhoods. Comparing crime rates alongside population helped provide a more meaningful view of differences between neighbourhoods.

The project also demonstrated how publicly available data can be used to investigate a real-world business and community problem and communicate data-driven findings.
